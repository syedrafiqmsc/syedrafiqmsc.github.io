Pandas, DataFrames, SQL and Matplotlib

Q1. What is Pandas?

Answer: Pandas is a Python library used for data manipulation and analysis.

Q2. What is a DataFrame?

Answer: A two-dimensional labelled data structure with rows and columns.

Q3. What is the difference between loc and iloc?

Answer: loc selects by labels; iloc selects by integer positions.

Q4. What does df.shape return?

Answer: A tuple containing the number of rows and columns.

Q5. What is the purpose of GROUP BY?

Answer: It groups rows with matching values so aggregate functions can be applied to each group.

Q6. What is a histogram?

Answer: A chart that displays the frequency distribution of numerical data using bins.
