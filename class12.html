1. Pandas DataFrame Practicals

A DataFrame is a two-dimensional labelled data structure consisting of rows and columns.

Program 1: Create a DataFrame

import pandas as pd

data = {
    'Arnab': [90, 91, 97],
    'Ramit': [92, 81, 96],
    'Samridhi': [89, 91, 88],
    'Riya': [81, 71, 67],
    'Mallika': [94, 95, 99]
}

df = pd.DataFrame(
    data,
    index=['Maths', 'Science', 'Hindi']
)

print(df)

Expected Output

SubjectArnab RamitSamridhi RiyaMallika
Maths9092898194
Science9181917195
Hindi9796886799

Program 2: Display rows and columns

print(df.head(2))
print(df.tail(2))
print(df.shape)
print(df.columns)
print(df.index)
print(df.dtypes)

Program 3: Select rows using loc and iloc

print(df.loc['Maths'])
print(df.loc['Science', 'Arnab'])
print(df.iloc[0])
print(df.iloc[1, 2])

Program 4: Boolean Indexing

print(df[df['Arnab'] > 90])
print(df.loc[:, df.loc['Maths'] > 90])

Program 5: Add a new column

df['Average'] = df.mean(axis=1)
print(df)

Program 6: Iterate through DataFrame rows

for subject, row in df.iterrows():
    print(subject, row['Arnab'])

2. Data Visualization with Matplotlib

Program 7: Line Chart

import matplotlib.pyplot as plt

subjects = ['Maths', 'Science', 'Hindi']
marks = [90, 91, 97]

plt.plot(subjects, marks, marker='o',
         label='Arnab')
plt.xlabel('Subjects')
plt.ylabel('Marks')
plt.title('Marks in Different Subjects')
plt.legend()
plt.grid(True)
plt.show()

Program 8: Bar Chart

plt.bar(subjects, marks, label='Arnab')
plt.xlabel('Subjects')
plt.ylabel('Marks')
plt.title('Subject-wise Marks')
plt.legend()
plt.show()

Program 9: Histogram

all_marks = [90, 92, 89, 81, 94,
             91, 81, 91, 71, 95,
             97, 96, 88, 67, 99]

plt.hist(all_marks, bins=5,
         edgecolor='black')
plt.xlabel('Marks')
plt.ylabel('Number of Scores')
plt.title('Distribution of Marks')
plt.show()

3. MySQL Practical Queries

Assume a table named STUDENT with columns RollNo, Name, Stream and Marks.

Basic and Aggregate Queries

SELECT * FROM STUDENT;
SELECT Name, Marks FROM STUDENT;
SELECT DISTINCT Stream FROM STUDENT;
SELECT * FROM STUDENT WHERE Marks > 80;
SELECT * FROM STUDENT WHERE Marks BETWEEN 70 AND 90;
SELECT * FROM STUDENT ORDER BY Marks DESC;
SELECT COUNT(*) FROM STUDENT;
SELECT MAX(Marks), MIN(Marks) FROM STUDENT;
SELECT AVG(Marks) FROM STUDENT;
SELECT Stream, AVG(Marks) FROM STUDENT GROUP BY Stream;
SELECT Stream, COUNT(*) FROM STUDENT GROUP BY Stream;
SELECT Stream, AVG(Marks) FROM STUDENT GROUP BY Stream HAVING AVG(Marks) > 75;
SELECT * FROM STUDENT WHERE Name LIKE 'A%';
SELECT UPPER(Name) FROM STUDENT;
SELECT ROUND(AVG(Marks), 2) FROM STUDENT;
These queries assume the table exists and contains the specified columns. Execute them in MySQL after creating and populating the table.
